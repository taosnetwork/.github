## Quem somos

A infraestrutura por trás do roleplay que sua comunidade merece.

Cansamos de ver comunidades de roleplay travadas em ferramentas genéricas e servidores instáveis. A Taos Network existe pra resolver isso: sistemas próprios, performance de verdade e uma equipe que trata cada projeto como se fosse o principal produto da empresa.

## Nossas criações

Nossa criação principal: um servidor de Multi Theft Auto construído com sistemas próprios de economia, eventos e monitoramento, sem plugins genéricos remendados.
